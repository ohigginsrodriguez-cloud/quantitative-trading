1. DESVIACIÓN ESTÁNDAR (STD)
────────────────────────────

Fórmula conceptual:
STD = √(promedio de (cada dato - media)²)

En tu código:
```python
desviacion_estandar = df_nvidia['Retorno'].std()
# Resultado: 3.254814682810059
```

¿Qué hace pandas aquí?
1. Calcula el promedio de los retornos (0.25%)
2. Resta ese promedio a CADA retorno
3. Eleva cada diferencia al cuadrado
4. Saca el promedio de todos esos cuadrados
5. Toma la raíz cuadrada

Ejemplo simplificado:
Si tienes retornos: [0%, 2%, -1%, 1%]
Media: 0.5%

Diferencias al cuadrado:
(0-0.5)² = 0.25
(2-0.5)² = 2.25
(-1-0.5)² = 2.25
(1-0.5)² = 0.25

Promedio: (0.25+2.25+2.25+0.25)/4 = 1.25
Raíz: √1.25 = 1.12%

STD = 1.12%


2. SESGO (SKEWNESS)
───────────────────

Fórmula conceptual (más compleja):
Sesgo = (suma de (cada dato - media)³) / (n × STD³)

Intuición:
- Si sesgo > 0: los datos están más dispersos a la DERECHA
- Si sesgo < 0: los datos están más dispersos a la IZQUIERDA
- Si sesgo = 0: distribución simétrica

En tu código:
```python
sesgo = df_nvidia['Retorno'].skew()
# Resultado: 0.545846882549258
```

Interpretación:
0.546 significa: hay un poco más de probabilidad de retornos altos
                 que de retornos bajos (bullish bias)


3. CURTOSIS (KURTOSIS)
──────────────────────

Fórmula conceptual:
Curtosis = (suma de (cada dato - media)⁴) / (n × STD⁴) - 3

La resta de 3 es porque:
- Distribución normal = curtosis 3
- Comparamos "cuánto más extrema" es que lo normal

En tu código:
```python
curtosis = df_nvidia['Retorno'].kurt()
# Resultado: 4.7245291150080515
```

Interpretación:
4.72 - 3 = 1.72 "más curtosis que lo normal"
Significa: 72% más probabilidad de eventos extremos
          que en una distribución normal

PARTE 9: FÓRMULAS QUE NECESITAS MEMORIZAR
═══════════════════════════════════════════════════════════════════════════════

1️⃣ DESVIACIÓN ESTÁNDAR
═════════════════════

σ = √( Σ(xi - μ)² / n )

Donde:
- σ = desviación estándar
- xi = cada dato
- μ = promedio
- n = número de datos
- √ = raíz cuadrada
- Σ = suma de todos

En Python:
```python
std = df['Retorno'].std()
```

2️⃣ SESGO (SKEWNESS)
═════════════

S = Σ(xi - μ)³ / (n × σ³)

Donde:
- S = sesgo
- ³ = elevado al cubo
- El resto igual que antes

Interpretación:
- S > 0: cola larga a la derecha (bullish)
- S < 0: cola larga a la izquierda (bearish)
- S = 0: simétrico

En Python:
```python
skew = df['Retorno'].skew()
```

3️⃣ CURTOSIS (KURTOSIS)
══════════════════════

K = [Σ(xi - μ)⁴ / (n × σ⁴)] - 3

Donde:
- K = curtosis
- ⁴ = elevado a la cuarta potencia
- El "-3" es para comparar con lo normal

Interpretación:
- K > 3: colas gordas (fat tails) - más crashes
- K = 3: distribución normal
- K < 3: colas delgadas - muy estable

En Python:
```python
kurt = df['Retorno'].kurt()
```

4️⃣ RETORNO PORCENTUAL
═════════════════════

pct_change = [(P_t - P_t-1) / P_t-1] × 100

Donde:
- P_t = precio hoy
- P_t-1 = precio ayer

Interpretación:
- Si retorno > STD: evento excepcional
- Si retorno > 2×STD: muy excepcional
- Si retorno > 3×STD: casi imposible (busca fraude o error)

En Python:
```python
df['Retorno'] = df['Close'].pct_change() * 100
```

5️⃣ WIN RATE
═════════

WR = (Trades Ganadores / Total Trades) × 100

Donde:
- WR = porcentaje de trades ganadores
- Válido si WR > 50% para estrategia rentable

Tu valor: 56% (bueno)

En Python:
```python
winners = (just_signals['Tomorrow_return'] > 0).sum()
win_rate = (winners / len(just_signals)) * 100
```

6️⃣ EXPECTANCY (ESPERANZA MATEMÁTICA)
════════════════════════════════════

E = (WR × Avg_Win) - ((1-WR) × Avg_Loss)

Donde:
- WR = win rate
- Avg_Win = ganancia promedio en trades ganadores
- Avg_Loss = pérdida promedio en trades perdedores

Interpretación:
- E > 0: estrategia rentable
- E < 0: estrategia no rentable
- E = 0: neutral

Tu valor: 0.356% (bueno para corto plazo)

En Python:
```python
avg_earnings = just_signals[just_signals['Tomorrow_return'] > 0]['Tomorrow_return'].mean()
avg_loss = just_signals[just_signals['Tomorrow_return'] < 0]['Tomorrow_return'].abs().mean()
expectancy = (0.56 * avg_earnings) - (0.44 * avg_loss)
```
