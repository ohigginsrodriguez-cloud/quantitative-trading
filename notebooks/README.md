# Notebooks - Analysis

Jupyter notebooks for interactive analysis and development.

## Files

- `01_nvda_analysis.ipynb` - NVIDIA distribution analysis and backtesting
- `03_btc_analysis.ipynb` - Bitcoin distribution analysis and backtesting  
- `04_apple_analysis.ipynb` - Apple distribution analysis and backtesting

## How to use

```bash
cd quantitative-trading
jupyter notebook
```

Then open any `.ipynb` file.
